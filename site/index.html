The best of both worlds

Installing an OS usually means burning a USB stick and rebooting, or running it slowly in a VM forever. No-Stick does neither.

Add a distro

Download one from the community catalogue, or point at an ISO you already have.

Install to a virtual disk

The distro's own installer runs in a quick, safe VM and installs into a disk-image file. Minutes, not reboots.

Boot it for real

Tick it into the No-Stick boot menu, then boot it at the next restart, or jump straight into it now. It runs on bare metal - full speed, all your hardware.

Safe by design: the installer runs in a sandboxed VM that can only see the virtual disk, never your real drives. Your existing system is never touched, and your boot menu gains exactly one new entry: No-Stick.

What it does

Try a distro live

Boot an ISO without installing anything, straight from your hard drive. New in this release, for Ubuntu, Mint, Debian and Arch ISOs.

Install to a VHD

A full, real install inside a file. Make as many as you like - each is just a file you can copy, back up or delete.

Dual-boot friendly

Windows and your current Linux stay exactly where they are. No partitions are created, resized or removed.

Your boot menu, your rules

Tick what appears in the menu, choose a default, and set a timer to boot it automatically. Or use Boot now to restart into a disk in seconds.

Tested on real hardware

Debian 13, Linux Mint 22 and Fedora 41 install and boot today, and Ubuntu uses the same method. Arch is experimental; the immutable distros are next.

Open source

MIT licensed and free, forever. Built with Visualised - the whole app is two readable files, so you can read exactly what it does before you run it.
